Ne kodlanacak, hangi sırayla, kim yapacak

Posterlerdeki vizyonun tamamı tek seferde yazılmaz. Önce Faz 1 (pilot MVP): Düvertepe'de 20 çoban, 300 hayvan, bir ürün hattı. Blokzincir, token ve yapay zekâ sonraki fazlara kalır.

Web sitesi mi, C# uygulaması mı? Web. Çoban telefondan, İstanbul'daki alıcı tarayıcıdan, yatırımcı panelden girecek; masaüstü uygulama kurduramayız. C# yine kullanılıyor: arka uç (sunucu/API) ASP.NET Core ile yazılır. Yani dışı web, içi C#.

Kim ne yapar

Y

Yiğit · yazılım

Kod yazan taraf. Veritabanı, API, ekranlar, QR, panel, yayına alma.

  • ASP.NET Core API + PostgreSQL
  • Web arayüzü (bu site + panel)
  • Formlar, QR, raporlar
  • Sunucu ve alan adı kurulumu

Ahmet Kalaycı · tasarım, saha, iş

Genel tasarımı ve içeriği belirleyen, sahayı ve paydaşları yöneten taraf. Yazılımın beslendiği gerçek veriyi getirir.

  • Ekranlarda ne görüneceğine karar
  • Pilot çoban/hayvan/parsel verisi
  • Mandıra, laboratuvar, kooperatif, alıcı görüşmeleri
  • Sahada test ve geri bildirim
