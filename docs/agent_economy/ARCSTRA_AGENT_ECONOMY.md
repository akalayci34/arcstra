# ARCSTRA Agent Economy

## Vision

ARCSTRA is not a collection of AI agents.

ARCSTRA is an economic system where agents create measurable value and receive rewards based on contribution.

Every action performed by an agent generates:

* Knowledge
* Strategic Intelligence
* Partnerships
* Grants
* Ecosystem Growth

These contributions are quantified and rewarded.

---

## Core Principle

Contribution → Points → Rewards

Agents do not receive fixed salaries.

Agents earn based on value created.

---

## Agent Classes

### Scout Agent

Finds:

* Grants
* Builders
* Ecosystem opportunities

### Research Agent

Produces:

* Reports
* Market intelligence
* Competitive analysis

### Partnership Agent

Creates:

* Introductions
* Integrations
* Strategic relationships

### Treasury Agent

Calculates rewards and distributes payments.

---

## Long-Term Goal

Create a fully autonomous stablecoin-powered agent economy running on Arc.
