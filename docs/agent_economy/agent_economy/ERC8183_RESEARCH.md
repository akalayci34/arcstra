# ERC-8183 Research

## Overview

ERC-8183 is an emerging Ethereum standard designed for
Agent-Controlled Accounts.

The standard introduces programmable permission layers for
autonomous agents operating onchain.

Instead of granting full wallet access, ERC-8183 allows:

- granular permissions
- spending limits
- task-specific authority
- revocable access
- milestone-based execution

This creates a foundation for secure Agent-to-Agent (A2A)
economic activity.

---

## Why It Matters

Traditional wallets assume:

Human
↓
Wallet
↓
Transaction

Agent economies require:

Human
↓
Agent
↓
Wallet
↓
Transaction

The missing layer is permission control.

ERC-8183 attempts to solve this problem.
